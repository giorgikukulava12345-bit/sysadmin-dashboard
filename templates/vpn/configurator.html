A dash means no native template in this tool. Unsupported choices block both outputs; algorithms are never silently downgraded. IKEv1 is provided for legacy interoperability. Prefer IKEv2 for new IPsec deployments.

Cisco VTI is a separate IKEv1 mode requiring IOS on both sides, using route-based any/any selectors. It creates Tunnel0, TS-VTI, IPSEC-PROFILE-VTI, MTU 1400/MSS 1360 and a rebuilt ACL NAT with correct computed wildcards. The default uses SHA256/DH14; the explicitly selected legacy lab profile uses DH2/SHA1. Review the existing NAT rule and reserved names before applying. No PFS is configured by this VTI profile.

01 / Design assumptions

IPv4, static endpoints with the public IP assigned locally, one non-overlapping LAN per site, PSK authentication, and preconfigured WAN/LAN interfaces. Documentation IPs are examples. NAT behind an upstream router, HA, VRFs, multi-VDOM and Advanced Routing Engine require design-specific changes. GRE uses IPsec transport mode and a dedicated /30 overlay; WireGuard uses its own fixed cryptographic suite.

02 / Deployment checklist

Reserve NOC-* object names, policy priority 100 and tunnel 100. Merge crypto maps with existing maps; a second map can replace the active attachment. Check WAN next-hop, zones, routing, NAT exemption and policy order before applying. RouterOS rules are placed before FastTrack/drop. FortiOS policies allow all services between the two LANs; narrow them for production. PAN-OS outputs a candidate configuration; validate and commit manually.

03 / Troubleshooting

No IKE SA: verify peer reachability, UDP 500/4500, PSK, identity, DH and Phase 1 proposal. IKE up but no ESP SA: compare mirrored selectors, Phase 2 proposal and PFS. SA up but no traffic: check routes, return path, NAT, security policy, FastTrack and packet counters. GRE adds MTU overhead; test path MTU and TCP MSS. Permit ESP (IP protocol 50) when NAT-T is not in use.

04 / Keys & validation

Generate distinct WireGuard key pairs on each router and enter the corresponding private/public values. A valid base64 format does not prove key-pair correspondence. Optional WireGuard PSKs must match. Secrets stay in this page's memory and are included in copied configurations; Clear secrets removes them from the tool. Templates have automated checks, but have not been executed on network appliances. Validate against your exact firmware and existing configuration.
